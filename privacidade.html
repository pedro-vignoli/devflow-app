Privacy Policy

DevFlow | Last updated: 2026-11-20

1. Who uses DevFlow

DevFlow is a personal, single-user tool. The only person whose data it handles is its owner.

2. Data we handle

When the owner connects a social media account, DevFlow receives an access token from that platform. The token is stored only on the owner's own computer and is used only to publish the owner's videos. DevFlow does not collect, sell or share data about any other person.

3. Websites

This website is static. It has no forms, no cookies, no analytics and no tracking.

4. Third parties

Videos and captions are sent only to the platform the owner chose, under that platform's own privacy policy.

5. Revoking access

The owner can revoke DevFlow's access at any time in the security settings of each connected account.

Politica de Privacidade

DevFlow e uma ferramenta pessoal, de uso unico do dono, e so trata os dados do proprio dono. Ao conectar uma conta, a plataforma entrega um token de acesso que fica guardado apenas no computador do dono e serve so para publicar os videos dele. Nao ha coleta, venda ou compartilhamento de dados de outras pessoas.

Este site e estatico: sem formularios, cookies, analise de acesso ou rastreamento. Videos e legendas vao so para a plataforma escolhida pelo dono, sob a politica dela. O dono pode revogar o acesso a qualquer momento nas configuracoes de seguranca da conta conectada.
